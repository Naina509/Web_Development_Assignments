Admission Overview

Welcome to GLA University. This handbook provides information about admission requirements, application procedures, required documents, important terms, fees, and contact details.

Eligibility

Application Process

Application Deadline: 30 June 2026

  1. Visit the official university admission website.
  2. Create a new applicant account.
  3. Fill in the online application form.
  4. Upload all required documents.
  5. Pay the application fee.
  6. Submit the application and save the confirmation.

Required Documents

  • Completed application form
  • Class 10 mark sheet
  • Class 12 mark sheet
  • Transfer certificate
  • Government-issued identity proof
  • Recent passport-size photographs
