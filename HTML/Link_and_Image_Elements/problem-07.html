Course Overview

Python Programming Fundamentals is a beginner-friendly course designed for students who want to learn programming from the ground up.

You will learn how to write Python programs, work with variables and data, use conditions and loops, create functions, and solve practical programming problems.

By the end of the course, you will have the confidence to write small Python applications and continue learning more advanced programming concepts.

Course Benefit: Python is widely used in web development, automation, data science, artificial intelligence, and software development.

Early enrollment offer: Enroll before September 15 and receive access to our bonus practice exercises.

What You Will Learn

The course begins with basic programming concepts and gradually introduces more practical Python features.

  • Understand Python syntax and programming fundamentals.
  • Work with variables, numbers, strings, lists and dictionaries.
  • Use if/else statements to make decisions.
  • Use loops to repeat tasks efficiently.
  • Create and use Python functions.
  • Read input and display useful program output.
  • Understand basic error handling.
  • Build small practical Python programs.

You will also practice problem-solving techniques that can be useful when learning data structures and algorithms.

Small Python Example

name = "Student"

for number in range(1, 4):
    print("Hello", name, number)

Duration

The course takes approximately 6 weeks to complete when studying for 4 to 5 hours per week.

  • Week 1: Python basics and variables
  • Week 2: Conditions and loops
  • Week 3: Strings, lists and dictionaries
  • Week 4: Functions and modules
  • Week 5: Files and error handling
  • Week 6: Mini project and revision
